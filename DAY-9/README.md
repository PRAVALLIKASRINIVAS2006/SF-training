# 🚀 Sprint 12 – From Developer Org to Production

## Placement Management System – Git, Salesforce CLI, Metadata & Deployment

> **"Writing code is only part of development. A professional developer must also know how to manage, test, review and safely deliver that code."**

---

## 📌 Overview

Sprint 12 focuses on moving the **Placement Management System** from a Salesforce development environment toward a professional, source-controlled and deployable application.

In previous sprints, the application was developed using:

- Salesforce Objects
- Apex Classes
- Apex Triggers
- SOQL & DML
- Queueable Apex
- Batch Apex
- Scheduled Apex
- Lightning Web Components (LWC)
- Flows
- REST API Integration
- Named Credentials
- External System Communication

As the application becomes larger, simply keeping the code inside a Salesforce Org is not sufficient.

This sprint introduces the professional development lifecycle:

```text
Development
     ↓
Git Version Control
     ↓
Feature Branch
     ↓
Code Review
     ↓
Testing
     ↓
Salesforce CLI
     ↓
Deployment
     ↓
QA / UAT
     ↓
Production
